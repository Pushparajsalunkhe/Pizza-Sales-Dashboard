# 🍕 Pizza Sales Report Dashboard

## 📊 Project Overview

This project analyzes pizza sales data using interactive dashboards. The dashboards provide insights into **sales performance, customer ordering patterns, and product trends**, helping stakeholders make data-driven business decisions.

The analysis covers:

* **Total Revenue**
* **Total Orders & Pizzas Sold**
* **Average Order Value**
* **Busiest Days & Months**
* **Top & Bottom Selling Pizzas**
* **Sales by Category and Size**
